Questions people ask first

Why do I need my own API key?

Because there is no server in the middle. TubeGist sends the transcript straight from your browser to Anthropic using your key, so nothing passes through us — and there's no subscription needed to cover infrastructure, because there isn't any. The trade-off is that you pay Anthropic for your own usage.

How much does the API usage cost me?

It depends on video length and the model you choose. On the default low-cost Haiku model a typical summary costs cents, not dollars. Exact usage is visible in your Anthropic console.

Does it work on videos without captions?

No. TubeGist reads the transcript YouTube already provides. If a video has no captions in any language, there is nothing to summarize.

Is it on the Chrome Web Store?

Not yet. Today it installs as an unpacked extension from a .zip file. If that's a dealbreaker for you, wait for the store release rather than buying now.

What data do you collect?

None. There is no account, no analytics and no backend. Your API key and preferences stay in your browser's local storage. See the privacy policy.
